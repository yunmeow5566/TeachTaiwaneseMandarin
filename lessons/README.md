# 教學內容和教案
在這裡我會放一些我自己想的教學內容，如果是教學的方式或主題歡迎自行取用（請不要拿去開課賺錢說是自己想的就好）。如果是我寫的範文請尊重並註明來源。

## 執行方向
在海外的華語課程中，如果不是用能力進行編班，而是以大致的年齡分班，老師很可能碰到同一班學生的程度落差很大的情形。能力落差通常是在閱讀和寫作上，當然也可能碰到學生口語表達也會有些困難。我的原則是，如果同學願意表達，即使是英文也沒關係，我會等他們說完後用華語再說一次讓他們可以學。對於有能力全華文表達的同學，我會很明確的要求他們要用華文跟我溝通，我也會盡所能的避免用英文解釋華文。

創作通常是激發學習動機的好方法。先藉由口述的方式表達意見，再根據學生的能力讓他們寫下來。
有些同學可能需要幫忙校對注音符號，有些同學可能想寫漢字，有些同學要畫圖，我認為只要願意把自己的想法表達出來都是很值得鼓勵的。
