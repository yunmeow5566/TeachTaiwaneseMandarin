# 緣起
在西雅圖慈濟人文學校教了一年的華語後，開始覺得有些我自己設計的教材可以分享給其他海外教華語的家庭和老師。
我不想用一般的社群網路，我也不想營利賺錢，分享教材的原因跟我成為人文學校老師的初衷一樣：希望能為下一代做些什麼。
隨著我開始認真用GitHub整理英文的教案，讓我來試試看在這裡分享華語教材吧！

# 我的海外華語教育理念
在大部分的情況下（我知道有例外），海外的兒少華語學習者會有至少一位監護人或照顧者的母語是華語，我認為這位成人是該學習者學華語的主要原因。
因此我把建立學習者與重要他人的連結視為海外學華語最重要的基礎。情感的連結會強化語言表達的動機，藉由高品質的互動加深對彼此的認識。
隨著學生年紀增長，能夠用華語表達主見和樹立自我的認同是下一個目標。
