# 我的海外華語教育理念
在大部分的情況下（我知道有例外），海外的兒少華語學習者會有至少一位監護人或照顧者的母語是華語，我認為這位成人是該學習者學華語的主要原因。
因此我把建立學習者與重要他人的連結視為海外學華語最重要的基礎。情感的連結會強化語言表達的動機，藉由高品質的互動加深對彼此的認識。
隨著學習者年紀增長，他們的當地強勢語言會主導價值觀和認知的形成，所以跟上認知發展並能夠用華語表達主見和樹立自我的認同是下一個目標。

## 家庭
幾年前某一天，當我在解釋金縷衣的詩句意義給我的孩子聽時，我突然領悟到在海外教下一代華語，重要的不是孩子在幾歲以前學會多少個字，而是在孩子十八歲以後我們能用華語文進行多少交流。
（現在看到這個句型有點尷尬，我發誓這句話在ＡＩ出來前我就講過了）
所以我在陪伴孩子學華語的時候，從來不求快（意思就是我不會想要什麼多少週就學會自行閱讀之類的課程），我很珍惜這些緩慢陪伴的時光。
作為一個很愛閱讀的人，我在家裡常常拿著圖書館借來的華文或英文書閱讀，可能是吃完飯後孩子在家裡到處蹦蹦跳跳的時候，也可能是週末全家人窩在家裡，孩子在忙他們的玩具事業的時候。
我了解並不是每個人的興趣都在閱讀純文字的書，所以我會建議家長們帶著孩子用華語做自己喜歡的事情：唱歌、看電影、玩遊戲都可以。
很多年以後，孩子會把華語經驗和跟家長緊密相處的時光連結在一起，他們或許不記得每一天發生的每件事情，但他們會記得跟重要的人在一起聽說華語的感受。


## 課後週末華語課
我自己沒有沉浸式雙語學校的經驗，所以這裡我只討論額外上課（平日下課後或週末）的情形。
我認為家長的態度是非常重要的。我個人很希望避免孩子明明不想來上課，但還是被家長要求來上課的情形。
而如果孩子已經來上課了，我會希望家長和學生的態度是：尊重學校和學習，對自己的時間負責。
我的理由是：只要有一個學習的場所用「有來就很好了」的態度來面對，這是對那個場所的不尊重，也會讓學生認為「有些學習的地方不用太認真也沒關係」。
我想應該沒有家長希望自己的小孩上大學也覺得「有來就很好了」吧！
