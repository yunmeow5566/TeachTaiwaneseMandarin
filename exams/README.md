## 考試時的漢字輸入
以上提到的考試都包含有寫作的部份，都是可以選擇繁體或是簡體來應試，但詞彙用語方面，即使使用繁體應試，感覺還是比較接近近代中國的用語。
考試的時候可以選擇拼音或是注音輸入法，但實體鍵盤上面是沒有注音符號的，應考者必須要自己記得鍵盤對應的位置（似乎STAMP可以帶著一張鍵盤對照表）。
我個人對於海外華語家庭要在何時開始打字的看法如下：
1. 如果平常的學校開始教英文打字(不是用平板那種虛擬鍵盤)，可以一併開始學習中文打字。
2. 如果學生喜歡寫作創作，打字可以讓中文寫作的能力持續成長。
3. 使用注音和拼音則是看家庭：如果注音很熟練而且家裡可以提供有注音符號的鍵盤，是有可能把打字練熟到考試不需要注音鍵盤的。
